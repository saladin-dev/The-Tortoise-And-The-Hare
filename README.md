# 🐢🐇 Turtle vs Rabbit Race (Python Edition)

A fun, randomized race simulation between a turtle and a rabbit!  
This project is a simple way to explore Python basics such as functions, conditionals, loops, and randomness.

---

## 🎮 Gameplay Overview

- The turtle moves forward a random distance between 0 and 15.
- The rabbit moves a random distance between 0 and 10 but can sleep or trip based on certain conditions.
- First to reach **location 10** wins the race.
- Funny race updates are printed each round to show the turtle and rabbit’s current positions.

---

## 🧠 Features

- Randomized race logic.
- Turtle always moves forward.
- Rabbit can **trip** or **sleep**, adding randomness to the race.
- Prints fun messages based on rabbit behavior.
- Text-based race simulation using the console.

---

## 🛠 Technologies Used

- **Python 3**
- Standard Python library: `random`
